- Role here: product and learning-method reference only

The Prosody Studio learning-loop specification independently adapts general
ideas such as active recall, immediate feedback, interleaving, adaptive
difficulty, mistake-driven practice, and spaced review to a native English
speaking application. This migration did not copy Fluent source files, prompt
text, data templates, or assets into Prosody Studio, and the application has no
runtime or build dependency on Fluent.

If future work copies or substantially adapts Fluent code or documentation, it
must retain the upstream MIT copyright and permission notice with the reused
material.

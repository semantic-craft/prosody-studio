# 英语口语练习闭环（草案）

状态：待用户评审
日期：2026-08-01

## 结论

Prosody Studio 是英语口语练习应用，不做通用语言课程，也不复刻命令行导师。
它吸收 Fluent 中与学习效果直接相关的原则，把它们收束成两个闭环：

1. **习得闭环**：选一句真实想说的话 → 听示范并看韵律 → 跟读录音 →
   立即看到转写、重音和升降调反馈 → 重试或存为错题。
2. **提取闭环**：看到语境或原表达 → 不看答案先开口 → 查看正确说法与一条
   可执行解释 → 自评或判分 → 按间隔计划再出现。

前者允许先听示范，因为任务是模仿；后者必须先回忆再揭晓，因为任务是提取。
二者共享同一份本地错题与复习状态，不另建互不相通的“课程”“打卡”数据。

Fluent 的 Python、shell、提示词、JSON 模板或素材复制进本仓。完整许可说明见

不是构建、运行或继续设计的依赖。

## 被采用的原则

| 原则 | Prosody Studio 中的落地 | 不采用的部分 |
|---|---|---|
| 主动回忆 | 复习与迁移题先说后揭晓；每次只呈现一个当前任务 | 不把答案或解题模式写进题面 |
| 即时反馈 | 一次尝试结束即给转写、正确说法、韵律偏差和下一动作 | 不堆成长篇通用语法课 |
| 真实错误驱动 | 跟读偏差和用户真实表达进入 `MistakeRecord`，再生成迁移练习 | 不维护脱离用户语境的大题库 |
| 间隔复习 | `ReviewCard` / `DrillProgress` 由 SM-2 安排到期时间 | 不用连续签到代替掌握度 |
| 交错练习 | 按错误类别轮换，避免连续刷同一种模式 | 不一次机械重复同题二十遍 |
| 合意难度 | 三档难度逐级调整；当前以 60%–80% 正确率为稳定带 | 不因单次错误跨多级跳变 |
| 本地可解释状态 | 错题、尝试、到期时间和掌握星级本地保存并可直接解释 | 不引入 Fluent 的六份 JSON 数据库布局 |

Fluent 文档常用 60%–70% 描述目标成功率。现有引擎使用 60%–80% 稳定带，
本规格暂时保留它：只有三档难度且短会话样本很少，较宽区间可减少来回抖动。
收集到真实会话数据后再单独校准，不能仅为“看起来一致”改常数。

## 单次练习的状态

```text
选择真实句子
  ├─ 习得：听示范 → 看韵律 → 跟读 → 即时反馈 ─┬─ 重试
  │                                              └─ 存为错题
  └─ 提取：看语境 → 先开口 → 揭晓/反馈 → 判分 ───→ 安排复习
                                                         │
                           到期后回到提取闭环 ←───────────┘
```

每个状态只给一个主动作。反馈至少回答三个问题：哪里不同、目标说法是什么、
下一次具体改什么。完美跟读不制造假错题；没有到期内容时，“加练”必须明确标注，
不能冒充到期复习。

## 信息架构

### macOS（主练习端）

保留并改造现有两个顶层屏幕，不重做第三套壳：

- **发音**（保留 `PronunciationScreen`）：负责习得闭环。句子选择、示范、
  韵律谱、录音、反馈和“存为错题”按一次任务的顺序排列。真实 TTS、ASR 与
  F0 对比仍分别由 issue 002–004 补齐。
- **练习室**（保留 `StudioScreen`）：负责提取闭环。到期复习优先，真实错题
  的迁移练习随后；没有到期内容时才提供明确标注的加练。

两个屏幕共享 `ReviewCard` / `MistakeRecord`，并保留“跟读反馈 → 练错词”的
直接跳转。完成真语音链路前，不为了导航重写已工作的学习状态。

### iOS（随身短练端）

现有“今日 / 表达 / 操练 / 复习”四标签是过渡结构：

- **今日**改为真正的会话入口，组合一条到期复习和一条跟读任务；
- **练习**最终承接表达、韵律与操练，不让用户先理解内部模块名；
- **复习**保留，承担短时主动回忆；
- 当前独立的“表达”与“操练”在直连语音链路完成前保留，之后并入“练习”，
  而不是长期维持四条割裂流程。

iPhone 默认短会话、单列、一次一个任务；macOS 可以同时展示更完整的韵律图和
解释，但两端使用相同的错题、评分与到期语义。

## 验收标准

后续实现应以真实用户路径验证，而不只看静态界面：

- 新用户能在一个入口内完成“听 → 跟读 → 反馈 → 重试/存错题”；
- 到期复习不显示答案，用户先开口后才揭晓并评分；
- 一次跟读偏差能进入练习室，并在正确作答后获得新的到期时间；
- 同一学习记录在 macOS 与 iOS 上含义一致；
- 无网络或语音服务失败时保留录音/重试路径，不伪造分析结果；
- 构建与运行均不需要 Fluent 仓库或其中任何文件。

## 暂不做

- 不迁入 Fluent 的 Claude Code 插件、技能或数据脚本；
- 不做通用多语言课程、排行榜或以 streak 为核心的游戏化；
- 不在本规格中改变 SM-2 公式、跨端同步方案或云端账号体系；
- 不在真 TTS / ASR / 音高链路明确前提前删除其依赖。
